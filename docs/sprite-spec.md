# 哈士奇序列帧素材规范

本文档面向「批量 AI 生成宠物动画帧」的素材制作。生成后放入 `assets/frames/<state>/`，运行 `npm run prepare:sprites` 自动完成去底、裁边、统一尺寸和 manifest 生成。

## 形象一致性（所有帧必须遵守）

以 `assets/raw/` 中 4 张参考图为基准：

- 哈士奇，灰白毛色、冰蓝色眼睛
- 身穿**藏青色西装外套 + 白衬衫 + 深色领带**
- 写实渲染风格，柔和影棚光
- **正面或微侧面视角**（桌面宠物面向用户，背面/全侧面仅适合特殊状态）
- 纯色浅灰背景（便于 rembg 去底），画面内无文字水印
- 构图：全身入画，四足着地，头顶和脚下留出约 10% 边距

## 各状态需求

| 状态 | 帧数 | 内容 | 说明 |
|------|------|------|------|
| `idle` | 2-4 | 站立呼吸：身体轻微起伏、耳朵小角度抖动、尾巴微摆 | 循环播放，首尾帧要能接上 |
| `walk` | 4-6 | 行走循环：四足交替迈步 | 朝**画面右方**走（程序自动翻转做反向）；循环步态 |
| `sit` | 1-2 | 坐姿，前腿直立、头微仰 | 2 帧可做眨眼 |
| `sleep` | 2 | 趴卧闭眼，身体随呼吸起伏 | 程序会叠加 Zzz 特效 |
| `happy` | 2-4 | 开心：歪头、吐舌、眼睛弯起 | 点击撒娇、提醒成功时用 |
| `jump` | 2-3 | 起跳瞬间：后腿蹬地、身体腾空 | 程序另有抛物线位移，帧只需姿态 |
| `bark` | 2 | 吠叫：张嘴/闭嘴两帧交替 | |
| `remind` | 3-4 | 兴奋提醒：前爪抬起、站立作揖或跳跃欢呼 | 提醒触发时播 3 秒，越显眼越好 |
| `drag` | 1-2 | 被拎着悬空：四肢下垂、表情无奈或懵逼 | 拖拽时显示 |

## 技术规格

- 格式：PNG，分辨率 ≥ 1024×1024（管线统一缩到 512 内）
- 命名：按帧序 `000.png, 001.png …` 放在 `assets/frames/<state>/` 目录
- 同一状态内所有帧的**角色位置/大小尽量一致**（管线只做去底和裁边，不做帧间对齐；位置漂移会导致播放抖动）
- fps 在 `tools/prepare-sprites.mjs` 的 `DEFAULT_FPS` 中调整

## AI 生成 prompt 模板

以参考图垫图（图生图/参考图功能）效果最佳。文字 prompt 参考：### 通用前缀

```
一只拟人化的哈士奇狗，灰白毛色，冰蓝色眼睛，穿藏青色西装外套、白衬衫和深色领带，
写实摄影风格，柔和影棚布光，纯浅灰色背景，全身像，正面视角，高清画质
```

### 各状态后缀（接在前缀后）

- **idle**：`自然站立，神态放松，舌头微吐`（生成后微调耳朵/尾巴角度出 2-4 张）
- **walk**：`正在迈步行走，侧面微转向前方，四肢交错`（连拍式 4-6 张步态）
- **sit**：`标准坐姿，前腿挺直，抬头挺胸，表情乖巧`
- **sleep**：`趴在地上，闭眼睡觉，下巴贴地，表情安详`
- **happy**：`开心表情，歪头吐舌，眼睛弯成月牙`
- **jump**：`兴奋起跳，前爪离地，身体向上跃起`
- **bark**：`张嘴吠叫，耳朵竖立`（+ 一张闭嘴版配对）
- **remind**：`两只前爪抬起作揖，站立姿势，表情兴奋急切`
- **drag**：`四肢下垂悬空，像被拎起来，表情无奈懵逼`

### 实用技巧

1. **垫图**：用 `assets/raw/wangcai_angle_front.png` 做参考图，锁定形象
2. **批量一致性**：同一状态用同一次会话连续生成，或用「局部重绘」只改四肢/表情
3. **去水印**：生成时关闭平台水印选项；残留的角标文字 rembg 通常能随背景一起去掉
4. **帧间对齐**：生成后用修图工具把角色移到画布中央再交给管线

## 🎬 视频工作流（推荐：动作更自然）

逐帧画图难以保证动作连贯，更顺的方式是**图生视频 → 抽帧**（你有 AI 视频工具链，直接复用）：

1. **垫图**：用 `assets/raw/wangcai_angle_front.png`（正面）或 `side.png`（走路）
2. **生成 2-4 秒短片**，纯色浅灰背景，镜头固定不动
3. 导出 mp4 放到 `assets/frames/<state>/`（文件名随意，如 `walk.mp4`）
4. `brew install ffmpeg`（首次需要）
5. `npm run prepare:sprites` —— 自动抽 8 帧（4fps）→ 去底 → 裁边 → 生成 manifest

视频 prompt 参考（垫图后输入）：

- **walk**：`哈士奇穿着西装向前走动，四肢自然交替迈步，侧面视角，循环步态，镜头固定`
- **sleep**：`哈士奇趴下睡觉，闭眼，身体随呼吸轻微起伏，镜头固定`
- **happy**：`哈士奇开心歪头，吐舌头，耳朵抖动，镜头固定`
- **remind**：`哈士奇兴奋地抬起前爪作揖，身体上下晃动，镜头固定`

> 注意：视频背景尽量纯色无杂物，镜头不要推拉摇移——抽帧后 rembg 逐帧去底，背景越干净效果越好。
